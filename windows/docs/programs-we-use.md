# Programs We Use

Programs with special settings, needed to recreate the environment.

## Hide the taskbar unless the Win key is pressed

1. Install [RoundedTB](https://github.com/torchgm/RoundedTB).
2. Set only the top margin to `2`. Do not check other options if you prefer the original Win11
   taskbar style.
3. In Windows settings, turn on **Automatically hide the taskbar**.

> [!NOTE]
> Press the Win key to show the taskbar and the Start menu.

## Faster keyboard repeat rate

Tool: [keyrate](https://github.com/EricTetz/keyrate)

Run with these arguments (delay in ms, repeat rate):

```sh
keyrate 150 1
```

## Clipboard manager

Tool: [Ditto](https://sabrogden.github.io/Ditto/)

## Minimize apps to the system tray

Tool: [RBTray](https://github.com/benbuck/rbtray)

Use it to move apps that pollute the Alt-Tab view to the system tray.

## Image viewer

Tool: [ImageGlass](https://imageglass.org/)

It opens images faster than the Windows **Photos** app.
